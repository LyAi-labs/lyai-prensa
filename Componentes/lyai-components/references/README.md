# Referencias Técnicas y Fragmentos de Código

Directorio reservado para snippets reutilizables entre verticales y proyectos de la empresa:

- **Shaders GLSL:** Funciones matemáticas de ruido Simplex/Perlin, raymarching, distorsión de dominio y filtros CRT/glow.
- **Web Audio DSP:** Módulos de filtrado biquad, analizadores FFT con smoothing personalizado y medidores RMS/Peak.
- **Utilidades UI/Canvas:** Algoritmos de easing, springs físicos, detección de colisiones de cursor y debounce/throttle deterministas.
