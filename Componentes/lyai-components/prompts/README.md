# Catálogo de Prompts de Referencia

Directorio reservado para almacenar prompts de sistema, meta-prompts de generación UI/UX, directivas de arte visual y plantillas de diseño para LLMs (Claude, Gemini, GPT).

---

## Estructura Sugerida

- `ui-generation/`: Prompts para solicitar componentes interactivos limpios a modelos de lenguaje (evitando "AI slop" o plantillas genéricas).
- `creative-direction/`: Prompts para estilos estéticos, paletas cromáticas y dirección visual en shaders o Three.js.
- `code-refactor/`: Prompts especializados para optimización algorítmica y minimalismo quirúrgico.
