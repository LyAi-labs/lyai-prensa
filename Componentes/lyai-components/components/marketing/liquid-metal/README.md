# Liquid Metal Hero

Animated WebGL shader background in the Liquid Metal style. Default variant. Generated by the 21st.dev Shader Builder. Adapted from Paper Shaders under Apache-2.0. 4-color palette (#09090B, #52525B, #D4D4D8, #FFFFFF). A drop-in, zero-dependency React component for hero sections and animated gradient/noise backgrounds.

- **Autor original:** Paper Design (@paper-design)
- **Referencia upstream:** [Liquid Metal Hero en 21st.dev](https://21st.dev/@paper-design/components/liquid-metal)
- **Categoría:** `marketing`
- **Stack:** React 18+, TypeScript, Tailwind CSS
